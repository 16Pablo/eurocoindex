Política de Privacidad

Última actualización: 21 de agosto de 2026

Esta Política de Privacidad describe cómo la aplicación móvil EuroCoinDex (en adelante, "la Aplicación") gestiona la información de sus usuarios.

1. Recopilación y Uso de Datos

EuroCoinDex no recopila, almacena ni transmite ningún tipo de información o dato de carácter personal.

  • No recopila información personal identificable (nombres, ubicaciones, cuentas).
  • No recopila diagnósticos, métricas de rendimiento ni registros de errores o cierres inesperados.
  • Toda la información introducida por el usuario permanece almacenada exclusivamente de manera local en la base de datos de su propio dispositivo.

2. Copias de Seguridad (Backup y Restore)

La funcionalidad de copia de seguridad utiliza el selector de archivos nativo del sistema operativo Android (Storage Access Framework). La Aplicación no tiene acceso general a la memoria del dispositivo ni lee archivos ajenos; únicamente lee o escribe el archivo de respaldo específico que el usuario selecciona de forma manual y voluntaria. Ninguna copia de seguridad se envía a servidores externos.

3. Servicios de Terceros y Publicidad

La Aplicación no integra herramientas de análisis, plataformas de rastreo, anuncios publicitarios ni kits de desarrollo de software (SDKs) de terceros orientados a recopilar datos.

4. Permisos del Dispositivo

La Aplicación no requiere permisos invasivos para su funcionamiento. En caso de que el sistema operativo o librerías de compatibilidad listen permisos técnicos menores (como conectividad o dispositivos cercanos), estos no se utilizan en ningún momento para recopilar, compartir o rastrear datos del usuario.

5. Privacidad de Menores

La Aplicación está diseñada para ser segura para cualquier público y no recopila datos de ningún usuario, incluidos menores de edad.
